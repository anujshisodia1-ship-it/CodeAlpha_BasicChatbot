# CodeAlpha Basic Chatbot 🤖

This is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

## Features

- Responds to "hello"
- Responds to "how are you"
- Responds to "bye"
- Handles unknown messages

## Technologies Used

- Python
- Functions
- While Loop
- If-Else Conditions
- User Input and Output
- String Methods

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Run `chatbot.py`.
4. Enter a message in the terminal.
